# Hermes Voice — мобильный клиент

Приложение для голосового разговора с Hermes: нажал кнопку, сказал, услышал ответ.
Микрофон и динамик — здесь; распознавание, модель и синтез — на сервере
([`hermes-voice`](../README.md)). Телефон остаётся тонким клиентом, поэтому
тяжёлые библиотеки в APK не едут.

## Что уже работает

- Двусторонний голосовой канал по WebSocket: PCM вверх, готовые аудиофайлы вниз.
- Конец фразы определяется на сервере по паузам — кнопку «стоп» между репликами
  нажимать не нужно.
- Ответ начинается с первого готового предложения, а не после того, как модель
  договорит целиком.
- Перебивание голосом (barge-in).
- Переключение режима на лету: **Быстрый** (модель напрямую) / **Агент** (Hermes
  с инструментами).
- Выбор голоса из списка, который отдаёт сервер.
- Текстовый режим — если говорить неудобно.
- Автопереподключение при обрыве связи.

## Запуск

Приложение не содержит собственных нативных модулей — только модули из Expo SDK
(`expo-audio`, `expo-file-system`, `async-storage`). Поэтому оно запускается
**в Expo Go без сборки**.

### По USB (надёжнее — без Wi-Fi и Tailscale)

```bash
npm install
dev-android.bat
```

Скрипт проверяет, что телефон подключён, пробрасывает порты через `adb reverse`
и поднимает Metro:

| Порт на телефоне | Куда ведёт | Зачем |
|---|---|---|
| `8081` | Metro на ПК | загрузка JS-бандла |
| `8643` | голосовой сервер на ПК | WebSocket-канал |

В настройках приложения укажи хост `127.0.0.1`, порт `8643`.

Требуется `adb` (platform-tools) и включённая отладка по USB на телефоне.
Если `adb` лежит не в `PATH`, путь правится в начале `dev-android.bat`.

### По сети

```bash
npx expo start
```

Дальше — `a` для Android или сканирование QR в Expo Go.

## Настройка

Настройки открываются ссылкой в шапке. Адрес сервера и голос сохраняются
в `AsyncStorage`, по умолчанию — `ws://100.79.158.109:8643/v1/voice`.

Адрес должен быть доступен с телефона. Если сервер за NAT — либо Tailscale
на обоих устройствах, либо проброс порта.

### Голос не хардкодится

В настройках голос по умолчанию — пустая строка, то есть «не выбирал». При
подключении клиент получает от сервера список доступных голосов и:

- если сохранённый голос есть в списке — оставляет его;
- если сохранённого нет или он в списке отсутствует — берёт серверный
  по умолчанию и запоминает его.

Это не перестраховка. У edge-tts и Piper **разные пространства имён**:
`ru-RU-SvetlanaNeural` против `ru_RU-irina-medium`. Сохранённый голос,
оставшийся после смены движка на сервере, сервер отвергает с ошибкой
`Неизвестный голос`, и озвучки не будет вовсе. Сверка со списком закрывает
этот случай молча.

## Как это устроено

```
микрофон → PCM 16 кГц → WebSocket ─┐
                                   ├─ сервер: VAD → STT → модель → TTS
динамик  ← файлы wav/mp3 ←─────────┘
```

Ключевая деталь протокола: **все бинарные фреймы между двумя `speech_chunk`
образуют один цельный файл**. Поэтому `ReplyPlayer` просто пишет пришедшие байты
в файл в кэше и проигрывает его — без склейки, без разбора контейнеров.
Расширение берётся из `hello.output.format` (`wav` у piper, `mp3` у edge).

| Файл | Назначение |
|------|------------|
| `src/config.ts` | адрес сервера и голос, хранение в `AsyncStorage` |
| `src/voice/protocol.ts` | типы событий сервера и команд клиента |
| `src/audio/recorder.ts` | микрофон → PCM-фреймы |
| `src/audio/player.ts` | очередь кусков озвучки, последовательное воспроизведение |
| `src/voice/VoiceSession.ts` | WebSocket, состояние диалога, переподключение |
| `src/screens/VoiceScreen.tsx` | единственный экран |

## Сборка APK

Сейчас сборка не нужна: приложение целиком на модулях Expo SDK, поэтому идёт
в Expo Go. Собственный APK понадобится для постоянного использования —
иконка на рабочем столе, без Metro.

Локальная сборка требует Android SDK и JDK — на машине разработки их пока нет.
Варианты:

1. **EAS Build** (облако): `npx eas build -p android --profile preview`.
   Не нужен локальный SDK, но нужен аккаунт Expo.
2. **Локально**: `npx expo prebuild -p android` и затем `gradlew assembleRelease`.
   Потребуется установить JDK 17 и Android SDK (несколько ГБ).

## Проверка перед запуском

```bash
npx tsc --noEmit
npx expo export --platform android --output-dir dist-check
```

Второй шаг важен отдельно от первого: `tsc` проверяет типы, но не проверяет,
что импорт существует в рантайме. Экспорт собирает реальный бандл и падает,
если модуль не резолвится. Эталон — 606 модулей, ~1.5 МБ.
